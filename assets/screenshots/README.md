# Screenshots and Demo Assets

Store the most important images for review and submission in this folder.

## Recommended files

- `dashboard-home.png` — main landing dashboard
- `prediction-result.png` — prediction output card or result screen
- `history-page.png` — prediction history / archive view
- `upload-flow.png` — upload and preprocessing flow
- `architecture-diagram.png` — system overview diagram

## Naming convention

Use lowercase names with hyphens, for example:

- `dashboard-home.png`
- `prediction-result.png`
- `cyclone-upload-flow.png`

## Notes

- Keep images compressed and legible.
- Prefer PNG or JPG for GitHub-friendly viewing.
- Update the README with the image references when real screenshots are added.
